Plugin Privacy Policy

Last updated: November 4, 2026

Overview

This policy covers the JobPilot plugin in ChatGPT ("the plugin"). The plugin has two parts: a set of instructions and reference files that runs inside ChatGPT, and four read-only job tools that ChatGPT can call on JobPilot's server, which is hosted on Deno Deploy. The job tools search public job boards, check whether a job link is still open, read the full text of a posting, and give facts about the JobPilot Chrome extension. The plugin has no JobPilot account and cannot connect to the Chrome extension. The Chrome extension has its own policy: Privacy Policy.

What JobPilot Receives Through the Plugin

JobPilot does not receive your conversations, the CV or other files you share, or the answers and cover letters written for you. When ChatGPT uses a job tool, JobPilot's server receives only what that tool needs:

  • search words for a role, for example "data analyst";
  • a job location to filter postings, for example "Lisbon" or "remote";
  • names of companies or job boards to search;
  • links to job postings to check or read.

The tools do not ask for names, contact details, CV text or any other personal data, and the plugin instructs ChatGPT never to send them. Tool requests reach the server from OpenAI's systems, not from your device. Like any web server, it sees the network (IP) address each request comes from.

How It Is Used and What Is Kept

  • Used only to answer. The server uses each request to look up public job boards (Greenhouse, Lever, Ashby, SmartRecruiters and Workday career sites) or to load the job page you asked about, and sends the result back to ChatGPT.
  • Nothing is stored. Search words, locations, company names and links are not saved in a database or written to our logs. The server's logs record only the time, the type of request, which tool was called, the response status and how long it took.
  • Abuse protection. To limit how often the tools can be called, the server counts requests per network address in memory for a few minutes, using a scrambled (hashed) form of the address that is never logged or saved.
  • Public job data only. Postings from public job boards (not your data) are kept in memory for about 10 minutes so that repeated searches are faster.

What the Plugin Works With Inside ChatGPT

While you use it, the plugin helps ChatGPT work with what you choose to share in the conversation, which can include:

  • Your CV: name, contact details, work history, education, skills and languages
  • Job postings and links you share or that Pilot finds with the job tools or web search
  • Your answers to application questions, cover letters and interview notes
  • The application tracker table (company, role, link, status, dates and notes)

This stays in ChatGPT and is used only to give you the help you ask for in that conversation: writing answers and cover letters, finding and checking job postings, keeping the tracker and preparing interviews.

Who Processes It

  • OpenAI operates ChatGPT and processes your conversations and files under its own privacy policy and your ChatGPT data controls. OpenAI also receives the job tools' results inside your conversation. JobPilot has no control over that processing.
  • Deno Land Inc. (Deno Deploy) hosts JobPilot's server and processes the tool requests described above on our behalf. As a hosting provider it may keep technical records of network traffic, such as IP addresses, under its privacy policy.
  • Job boards and job sites. To answer a tool request, JobPilot's server contacts the public job board or the web page of the link being checked. They receive a request from our server for that company or posting, not your identity or network address.
  • Websites you visit. Any site you open from a link has its own privacy policy.

JobPilot does not sell or share data from the plugin for advertising.

Retention

JobPilot keeps nothing you share through the plugin. Tool requests are answered and not saved; the in-memory counters and the job board cache are cleared within minutes. The server's request logs, which contain no request contents, are kept by Deno Deploy for a limited period. Your chats and files are kept by OpenAI according to your ChatGPT settings and OpenAI's policies. The application tracker exists only in the conversation and in any CSV file you download.

Your Controls

  • You decide what to share. You can remove ID numbers, date of birth and home address from your CV before sharing it.
  • You can ask Pilot not to use the job tools, and use web search or your own links instead.
  • You can delete conversations, and manage memory and model-training settings, in ChatGPT's settings.
  • You can uninstall the plugin from the Plugins page in ChatGPT at any time.
  • For any question or request about your data, write to support@jobpilot.pt.

What Not to Share

Do not share passwords, one-time codes, API keys, government ID numbers (passport, national ID, tax or social security numbers) or bank or card details. Pilot never asks for them, and if you share them by mistake it will tell you, will not repeat them and will not send them to any tool.

Links to JobPilot

When you ask for forms to be filled, the plugin may give you a link to download the JobPilot Chrome extension. If you install it, the extension's privacy policy applies.

Children

The plugin is not directed at children under 13.

Changes to This Policy

If the plugin changes what it sends to JobPilot, for example if a future version connects to a JobPilot account, this policy will be updated before that version is released, to describe what data then reaches JobPilot, why, who receives it, how long it is kept and how to control it. The "Last updated" date shows the latest change. The Terms of Service also apply to the plugin.

Contact
